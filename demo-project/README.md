# 🌊 Vibe-Check

A system-intimate tool to monitor the "vibe" of a project.

## Core Concept
- Watches the current directory for changes.
- Analyzes commit messages and code complexity.
- Provides a "Vibe Score" (0-100) and a matching emoji.

## Current State
- `main.go` is just a skeleton.
- No actual directory watching logic implemented yet.
- Vibe scoring algorithm is just a placeholder.
- Needs a way to export vibe history to a JSON file.
- The Shadow Auditor will probably hate the lack of concurrency safety.

## Goal
Make it fast, make it cheeky, and ensure the vibe is always high.
